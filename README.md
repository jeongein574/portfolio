This is Ein's personal portfolio website built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.  
This site showcases my projects, research experience, and background with smooth scroll animations and responsive design.

## Features

- **Responsive Design** — works on all screen sizes
- **Framer Motion Animations** — smooth scroll and reveal transitions
- **Dynamic Experience Timeline** — scroll-linked icons with progress animation
- **SEO Optimized** — metadata configured for better visibility
- **Dark Mode Support** — theme toggling using Tailwind’s dark class

## Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Deployment:** Vercel / GitHub Pages
